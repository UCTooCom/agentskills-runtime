## 🍔 用餐｜把饭点安排明白

**麦当劳怎么吃，交给 AI。**

- **做什么：**用麦当劳 MCP 做一个 AI 作品，形式不限，Skill、Agent、网页、小程序、机器人都行。比如套餐推荐助手、麦门省钱助手（凑出最划算的一单）、聚餐一键点麦当劳、按热量和口味配套餐、活动和新品推荐，也可以自拟。做成 Skill 的，同一个作品还能同步参加麦当劳程序员创意开发大赛（10/25 23:59 截止），两边的奖都有机会拿。

- **用什么：**麦当劳 MCP（赛前用手机号在 [open\.mcd\.cn/mcp](https://open.mcd.cn/mcp) 登录，申请 MCP Token）＋建议用 WorkBuddy 开发，在它的连接器里配好 mcd\-mcp 就能调用；用 WorkBuddy 做的才评赛道前三。

- **交什么：**能用的作品（链接、GitHub 仓库或安装包都行）＋一段使用说明或录屏；用 WorkBuddy 做的，再附一份 workbuddy\.md（开发对话记录）。想同步参加麦当劳大赛的，按对方要求建一个公开的 GitHub 仓库，放好 README\.md、CONTEST\_DECLARATION\.md、MCP\_INTEGRATION\.md、源代码和 workbuddy\.md，提交到赛事站时填仓库地址，再去麦当劳大赛仓库发一条报名 Issue。

- **评委看什么：**真的调用了麦当劳 MCP，能跑通，实用或好玩至少占一样，有人真的用过加分。

- **参考：**[麦当劳程序员创意开发大赛（规则、MCP 配置、报名 Issue 格式）](https://github.com/M-China/mcd-developer-innovation-challenge)

## 💼 办公｜让 AI 真的 Work

**给自己搭一个 AI 工作台：每天上班先打开它，重复的活交给它。**

- **做什么：**把你每天要看、要做、要交的收进一个工作台，比如一早打开就有今日待办和日程、会议纪要一键变待办、日报周报自动起草。至少收进 3 件你每天真在做的事。

- **进阶挑战（选做，做到了明显加分）：**接真实数据（日历、邮箱、飞书或表格）、自己跑起来（定时或来了新消息就自动干活）、换人也能用（同事换上自己的数据，10 分钟能配好）。

- **用什么：**建议用豆包工作，用它做的才评赛道前三。

- **交什么：**能打开的工作台＋3 分钟以内的使用录屏（演示你的一天，内容请脱敏）＋一句「原来每天花多久，现在多久」；用豆包工作做的，另交三句话人物卡（我是谁、原来卡在哪、现在怎样）和分享链接。

- **评委看什么：**是不是真的每天在用，省下多少时间，打开就会用；进阶做到越多，分越高。

## 🎬 短剧｜三分钟，拍出电影感

**拍一部 3 分钟以上、有电影感的 AI 短片。**

- **做什么：**5 个主题选一个。重启（一个人、一座城或一段关系，按下重启键之后）、平行世界（另一个选择、另一个自己）、我的城市（用你所在的城市讲一个故事）、AI 来了以后（AI 走进日常后的一天）、1024（和程序员节、代码或数字 1024 有关）。剧情、动画、MV 式叙事都行。

- **用什么：**工具不限，视频生成、配音、配乐自选。

- **交什么：**3 分钟以上的横屏成片（16:9，1080p 及以上）＋一页创作说明（主题、故事梗概、用到的工具），注明素材和音乐来源。路演放 2 分钟以内的精华，完整版评委在赛事站看。

- **评委看什么：**故事完整，有电影感（画面、镜头、声音），主角前后不换脸，主题用得巧。

## 🔍 侦探｜查得到，信得过

**少点幻觉，多点搜索：丢给它一个问题，它去全网查清楚，带着证据回来。**

- **做什么：**围绕「少点幻觉，多点搜索」，用元宝搜索做一个会查的 AI 作品，题材和形式都不限，网页、机器人、Skill、应用、小游戏都行。比如查家族群传言的真假、查演唱会还有没有票、找一部只记得剧情的剧，也可以完全自己出题。核心是搜索：去掉元宝搜索，作品就转不起来。不碰时政和涉及个人的消息。

- **进阶挑战（选做，做到了明显加分）：**深度调查（自己拆步骤、多轮搜索、交叉比对，交一份带证据链的调查报告）、持续盯梢（每天自己去查，有变化就提醒）、截图查证（丢一张截图或一段视频里的说法，先认出再去查）。

- **用什么：**建议用元宝搜索，用它做的才评赛道前三；侦探赛道选手每人每月 6000 次免费搜索，领取见第四节。

- **交什么：**能打开的作品（网页、机器人、Skill、应用或小游戏都行）＋3 次真实查询的录屏或截图，每次都有结果和点得开的来源；做了进阶的，另交对应演示。

- **获奖条件：**把作品公开发到小红书或视频号，不限粉丝数，带上话题 \#元宝搜索 \#WaytoAGI \#AI切磋大会 \#1024超能Coding周末，并在作品提交页补填分享链接，最晚 10/25 23:59（作品本身仍是 16:00 提交截止）。没有分享的，不评侦探赛道前三和 10 名优秀奖，照常参评本地前三和 1024 超能大奖。

- **评委看什么：**搜索是作品的核心，查得准，来源点得开，查不到敢说不知道，好用或好玩；问题越难、越有人真在用，分越高。

## 🧑‍💻 OPC｜一个人就是一家公司

**两天，一个人加 AI，做出一个能对外服务的产品。**

- **做什么：**找准一类客户，做一项能接单的服务，比如小店营销、自由职业者报价、知识服务自动交付。

- **用什么：**工具不限。

- **交什么：**能用的产品＋一份样例交付，讲清服务谁、怎么收费。

- **评委看什么：**需求真实，服务能用，交付有价值，商业思路清楚。

## 🎮 游戏｜让人想再玩一局

**一句话变出主角，做一局让人想再玩的游戏。**

- **做什么：**用一句话、一张草图或一张照片生成角色和道具，做成能玩的小游戏，比如自家猫当主角的闯关、bug 怪物解谜、派对小游戏；2D、3D 都行。

- **用什么：**工具不限，角色和道具用 AI 生成，再用 AI 编程工具做成网页游戏。

- **交什么：**浏览器或手机能直接玩的链接，从开始到重开能完整玩一局，操作提示放进游戏；另交 1 张主角卡（一句话或草图、生成的角色、游戏里的样子）。

- **评委看什么：**一看就会玩，能完整玩一局，主角有记忆点，玩完还想再来一局。

## Toklens 算力（所有选手）

1. 赛前注册 toklens\.ai，完成邮箱验证。没验证的账号兑换时会提示「请先完成注册」。

2. 10/24 10:30 后，在「我的福利」领一个兑换码，一人一个。

3. 登录 toklens\.ai，点左侧「活动」，在「兑换活动礼品卡」输入兑换码；同一页点「创建 GPT 分组 Key」。**Key 只完整显示这一次，马上复制保存。**

4. 接入工具：用 Codex 的，在「接入工具」页复制一键配置命令到终端运行，看到 TOKLENS\_OK 就通了；其他工具 Base URL 填 `https://lax.toklens.ai/v1`（OpenAI 兼容）。

兑换后 3 天内有效，建议开赛当天再兑换；每个账号只能兑换一张。详细步骤看 [toklens 接入指南](https://ucnqmgl479j8.feishu.cn/docx/Jd3Md7uHaocDuEx7wSicbejRnKg)。

## OpenDev 算力（短剧、游戏、OPC）

一人一份，报了不止一条也只领一次。领取时要**锁定一条赛道**（短剧、游戏或 OPC）并写一句话选题，锁定后不能再换，作品要交到这条赛道。

2. 打开 [OpenDev 活动加入入口](https://credits.openai-next.com/join/waytoagi1024coding)，点「使用 OpenDev 账户激活」，用锁定时填的邮箱注册或登录。提示找不到邀请的，稍等几分钟再试。

3. 点「创建 API Key」，马上复制保存。OpenAI 兼容工具 Base URL 填 `https://api.openai-next.com/v1`；Claude Code 和 Claude 桌面版填 `https://api.openai-next.com`（不带 /v1）。做短剧的可以直接调图像、视频、音乐模型。
