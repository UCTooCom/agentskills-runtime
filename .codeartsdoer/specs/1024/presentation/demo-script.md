# T-26 演示素材脚本（8 屏分镜）

> 用途：赛事演示材料（spec §4.6 第 5 条：≥3 次真实查询 + 可点开来源）。
> 状态：命令、期望输出、解说词已由 AI 写好；标注 **【人工】** 的项需你实际执行并截图/录屏。
> 截图存放：`.codeartsdoer/specs/1024/presentation/shots/`，文件名见每屏「存为」。
> 时间盒：录制 + 截图 ≤ 40 min。
> 内容禁区（§4.6 第 8 条）：不涉时政评论与特定个人——三家企业均为公开工商信息主体，只谈政策申报条件。

## 屏 1 · 痛点：政策查得到，但不敢信

**画面**：一屏文字 + 一张真实检索结果截图（普通搜索引擎，满屏「代办」「包过」「内部渠道」）。

**解说词**（约 25 秒）：

> 中小企业查政策，从来不是查不到，而是**查到了不敢信**。
> 搜出来的前几条是代办广告，你不知道哪条是官方原文、哪条已经过期、
> 哪条是别的省市的政策被搬到这里。
> 更麻烦的是 AI 会给你编一个看起来很像的答案——它不说「我不知道」。

**存为**：`01-pain.png`

**【人工】**：补一张本地检索结果截图即可（任意政策关键词），不必是本项目产物。

## 屏 2 · 自检：通道是活的，档位是旗舰版

**画面**：终端执行自检，输出完整可见。

**命令**（工作目录 `skills/yuanbao-search`）：

```bash
node --experimental-strip-types scripts/yuanbao_search.ts --selftest
```

**期望输出**（实测值，TS 版）：

```
HTTP 200 / Version=flagship / 10 条
authority_level 10/10 可用 / score 10/10 可用
deeplinks 0/10（未请求 Deeplinks，缺失不视为错误）
政策原文库可用（74 条）
耗时 2.3s
```

**解说词**（约 20 秒）：

> 第一步先自检：通道通不通、服务档位是不是旗舰版、权威度字段今天有没有给。
> 权威度字段是服务端给的，哪天不给了，我们不是假装它还在，
> 而是把这个因子记成「不可用」并整体降一档。

**存为**：`02-selftest.png`

**【人工】**：执行一次，截图终端输出。若 `Version=standard` 属正常降级事件，解说改为「今天档位是 standard，权威度缺失，我们照实降级」。

## 屏 3 · 真实查询一：北京北辰实业有限公司

**画面**：三段并排或上下滚动——① 检索命令 ② 单行 JSON 输出（`jq` 美化后截取前 3 条）③ 报告的「可采信」章节。

**命令**（闭环 Step 1→3）：

```bash
SK=../beichen-policy-assistant/scripts

node --experimental-strip-types $SK/build_enterprise_profile.ts --company "北京北辰实业有限公司"
node --experimental-strip-types scripts/yuanbao_search.ts \
  --query "北京 专精特新 中小企业 扶持 政策 申报" \
  --industry gov --cnt 50 --freshness 1y --json
```

**期望输出**（实测联调数据）：

| 项 | 值 |
|---|---|
| RequestId | `11a6c990-f69b-4ef5-9291-e87c4cf73375` |
| Version | flagship |
| items / excluded | **13 / 7** |
| 匹配结论 | 5（覆盖率 1.0） |
| 检索侧绑定 `policy_no` | 0（13 条转待核实） |

**解说词**（约 30 秒）：

> 50 条原始结果进去，13 条出来。
> 每条带四因子标签：权威度、信源分级、时效、有没有命中本地政策原文库。
> 最关键的是这条 `reason`——它不是一句「可信」，
> 而是把四个因子怎么判的、为什么这么判，全写在里面。

**存为**：`03-query1-beichen.png`

**【人工】**：执行并截图。**重点**：截图里要能看到至少一条 `url` 是 `.gov.cn` 结尾，且**可点开**（鼠标悬停或浏览器打开一次录进去）。

## 屏 5 · 敢说不知道（**这一屏是全场核心，务必单屏**）

**画面**：终端里 `excluded[]` 的完整输出 + 报告里「未查到可靠依据」章节并排。
必须能看到每条被排除项**带原因**。

**命令**：

```bash
node --experimental-strip-types $SK/generate_policy_report.ts \
  --profile output/profiles/<画像>.json \
  --matches output/matches/<匹配>.json
```

**期望输出**（实测）：

- 「未查到可靠依据」章节实际渲染出 **13 条排除项及原因**
- 排除原因分布（50 条批次实测）：**未知站点 / 自媒体 21 条、过期 1 条**

**解说词**（约 35 秒）：

> 这一屏是我最想让评委看的。
> 被排除掉的 13 条，我没有丢掉它们，也没有硬塞进报告——
> 它们单独成章，每一条都写明为什么：这条是自媒体发的，查不到发布主体；
> 那条是 2019 年的，早过期了。
>
> 我把这条规则叫「可核验出处」：
> **敢说不知道，不是本地库里没有就说不知道，而是拿不出可核验出处时才说不知道。**
> 一个 `.gov.cn` 的官方页面，URL 点得开、发布日期看得见，它本身就是可核验出处——
> 哪怕我本地原文库里没备案，我也敢采信，只是标一句「需人工复核」。

**存为**：`05-excluded.png`

**【人工】**：执行并截图。**要求**：`excluded[]` 至少 5 条原因在画面内可读，不要只截一行。

## 屏 6 · 异常用例：把原文库删了，它还能说实话

**画面**：临时改名 `knowledge/policy-index.json` → 执行检索 → 输出 warning + 结论分布 → 还原。

**命令**：

```bash
mv ../beichen-policy-assistant/knowledge/policy-index.json /tmp/policy-index.json.bak
node --experimental-strip-types scripts/yuanbao_search.ts --query "…" --cnt 30 --freshness 1y
mv /tmp/policy-index.json.bak ../beichen-policy-assistant/knowledge/policy-index.json
```

**期望输出**（实测 G14）：

- 退出码 **0**、`ok=true`（流程不中断）
- warning：「政策原文库不可用…非政府信源的结论将置待核实」
- 20 条中 **7 条被排除**，剩余 13 条 `authority=高`（政府信源）仍可采信

**解说词**（约 25 秒）：

> 我把事实底座抽掉，看它会不会塌。
> 结果是：没有塌，也没有硬撑。它明确告诉你底座没了，
> 然后把那些「本来就不是官方一手来源」的结论全部标成待核实——
> 政府信源的 13 条仍然可采信，因为它们的出处自己就能核验。
> 退出码 0，流程不中断。**索引已还原**（这句要真的做到）。

**存为**：`06-anomaly.png`

**【人工】**：执行并截图。**务必确认索引已还原**（跑完 `ls` 一下给观众看）。

## 屏 7 · 绝活：删掉源码，照样跑

**画面**：左右对比——左边是 `yuanbao-policy` 目录树（**无 `src/`**），
右边是宿主加载该目录后一次检索的成功输出。

**命令**：

```bash
# 复制分发目录并删掉源码
cp -r skills/yuanbao-policy /tmp/dist-yuanbao-policy
rm -rf /tmp/dist-yuanbao-policy/src
# 【人工】宿主加载 /tmp/dist-yuanbao-policy，执行一次检索
```

目录树（删源码后）：

```
yuanbao-policy/
├── plugin.yaml
├── SKILL.md
└── target/release/bin/skill_yuanbao_policy.exe   ← 编译产物 + 同目录 DLL
```

**解说词**（约 35 秒）：

> 最后一屏是绝活。
> 我把这个检索内核的源码整个删掉，只剩一个 exe 和一份清单，
> 宿主照样加载、照样返回带可信度标签的结果。
>
> 脚本型技能做不到这件事——JS 和 Python 必须以明文源码分发。
> 而这一轨是编译产物：**能力可以交付，源码不必交出去。**
>
> 顺带说一句，这个插件是仓颉写的，四轮编译才过：
> `init` 和 `match` 是关键字不能当函数名、`HashMap[key]` 返回的是值不是 Option、
> 数组初始化的 lambda 不能捕获可变变量。
> 每一轮都是我（AI）写、人编译、我按日志修——这就是我们说的 AI 驱动开发。

**存为**：`07-closed-source.png`

**【人工】**：**依赖 T-23/T-24 先通过**。若时间不够，本屏降级为「只展示 exe 产物 + 目录树截图」，解说保留但明说「加载演示待补」。

**画面**：一屏四行，诚实写边界。

> 最后说清楚它现在做不到什么：

> 下一步是扩原文库、把编号绑定做上去，以及把这套四因子规则开放成可插拔组件。
