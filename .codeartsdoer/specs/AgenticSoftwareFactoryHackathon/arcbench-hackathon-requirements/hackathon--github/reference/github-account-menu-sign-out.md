# github-account-menu-sign-out.png — GitHub 仪表盘/主页

## 页面用途
GitHub 用户登录后的主页/仪表盘，展示仓库、动态信息流，右上角含用户头像菜单（含退出登录选项）。

## 布局结构
经典三栏混合布局：顶部全宽导航栏 + 左侧窄边栏 + 主内容宽栏 + 底部页脚。

## 主要UI元素
- **顶部导航**：汉堡菜单、GitHub Logo、"Dashboard"文字、搜索框（"Type / to search"）、用户头像下拉菜单（含绿色在线状态）、+号创建按钮、通知铃铛
- **左侧边栏**："Top repositories"标题、绿色"New"按钮、仓库搜索框、仓库链接
- **AI助手区**：大输入框（"Ask anything or type @ to add context"）、"Ask"下拉、"All repositories"下拉、发送按钮
- **快捷操作**："Agent"、"Create issue"、"Write code"、"Git"、"Pull requests"按钮
- **Feed区**："Feed"标题、"Filter"按钮、"Trending repositories"标签、仓库卡片（含Star按钮）
- **页脚**：GitHub Logo+版权、Terms、Privacy、Security、Status、Community、Docs等

## 颜色样式
- 页面背景：浅灰白 #F6F8FA
- New按钮：绿色 #2EA44F
- 主内容卡片：白色背景，圆角
