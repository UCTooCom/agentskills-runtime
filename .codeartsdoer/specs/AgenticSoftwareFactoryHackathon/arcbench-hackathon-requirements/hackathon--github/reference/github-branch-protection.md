# github-branch-protection.png — GitHub 分支保护规则配置页

## 页面用途
GitHub 仓库设置中的分支保护规则配置页面。

## 布局结构
左侧设置导航栏 + 右侧主内容区。顶部有仓库名称和全局导航栏。

## 主要UI元素
- **左侧导航菜单**：General、Collaborators、**Branches**（当前选中）、Tags、Rules、Actions、Webhooks等
- **主内容区**：信息卡片、两个操作按钮
