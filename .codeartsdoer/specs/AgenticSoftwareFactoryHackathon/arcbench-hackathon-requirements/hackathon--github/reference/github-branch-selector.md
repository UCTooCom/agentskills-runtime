# github-branch-selector.png — GitHub 分支选择弹窗

## 页面用途
分支切换/选择弹窗。

## 布局结构
页面中央弹出分支选择面板。

## 主要UI元素
- **搜索框**：Find or create a branch...
- **标签页**：Branches、Tags
- **分支列表项**：main（带勾选标记、default标签）
- **链接**：View all branches
- **关闭按钮**：×

## 关键可见文字
Switch branches/tags、Find or create a branch...、Branches、Tags、main、default、View all branches
