# github-code-clone-menu.png — GitHub 代码克隆菜单

## 页面用途
展示代码克隆选项的下拉菜单，在仓库主页Code按钮展开。

## 布局结构
下拉面板，含标签页和克隆方式选项。

## 主要UI元素
- **标签页**：Local、Codespaces
- **克隆方式**：HTTPS、SSH、GitHub CLI
- **URL输入框**：含复制按钮
- **功能链接**：Open in GitHub Copilot app、Open with GitHub Desktop、Download ZIP
