# github-create-branch.png — GitHub 分支管理页面

## 页面用途
仓库分支管理页面，展示所有分支列表。

## 布局结构
顶部标题区 + 筛选标签 + 搜索框 + 分支表格。

## 主要UI元素
- **页面标题**：Branches
- **新建按钮**：New branch（绿色）
- **筛选标签**：Overview、Yours、Active、Stale、All
- **搜索框**：Search branches...
- **表格列**：Branch、Updated、Check status、Behind、Ahead、Pull request
- **分支行**：main（Default标签、复制按钮、删除按钮）

## 关键可见文字
Branches、New branch、Overview、Yours、Active、Stale、All、Default、Branch、Updated、Behind、Ahead、Pull request、main
