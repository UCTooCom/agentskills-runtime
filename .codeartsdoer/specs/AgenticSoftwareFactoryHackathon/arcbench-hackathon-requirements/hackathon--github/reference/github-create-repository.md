# github-create-repository.png — GitHub 创建新仓库页面

## 页面用途
GitHub 创建新仓库（New repository）页面，引导用户创建新代码仓库。

## 布局结构
顶部导航 + 居中表单布局，分两步骤区域：General（基本信息）和 Configuration（配置选项）。

## 主要UI元素
- **页面标题**："Create a new repository"
- **步骤1 General**：
  - "Owner *"下拉框（带用户头像）
  - "/"分隔符
  - "Repository name *"文本输入框
  - "Description"文本框（附字符计数"0 / 350 characters"）
- **步骤2 Configuration**：
  - "Choose visibility *"下拉框（Public）
  - "Add README"开关控件（Off状态）
  - "Add .gitignore"下拉框（No .gitignore）
  - "Add license"下拉框（No license）
- **提交按钮**："Create repository"（绿色）

## 颜色样式
- 背景：浅灰 #F6F8FA
- 必填标记：红色星号*
- 提交按钮：绿色 #2DA44E
- 提示链接：绿色 #1A7F37
