# github-default-branch-settings.png — GitHub 默认分支设置页

## 页面用途
GitHub 仓库设置中的默认分支配置页面。

## 布局结构
左侧设置导航栏 + 右侧主内容区。

## 主要UI元素
- **左侧导航菜单**：**General**（当前选中）、Collaborators、Branches、Tags、Rules等
- **主内容区**：Default branch信息卡片、操作按钮
