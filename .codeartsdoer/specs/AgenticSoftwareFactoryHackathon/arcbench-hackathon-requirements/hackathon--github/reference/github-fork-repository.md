# github-fork-repository.png — GitHub 创建 Fork 页面

## 页面用途
GitHub 创建新 Fork（仓库复刻）的页面。

## 布局结构
顶部仓库来源信息 + 下方表单区域 + 底部创建按钮。

## 主要UI元素
- **表单字段**：Owner下拉框、Repository name输入框、Description文本框
- **复选框**：Copy the master branch only
- **创建按钮**：Create fork

## 关键可见文字
Create a new fork、A fork is a copy of a repository、Owner、Repository name、Hello-World is available、Description、Copy the master branch only、Create fork
