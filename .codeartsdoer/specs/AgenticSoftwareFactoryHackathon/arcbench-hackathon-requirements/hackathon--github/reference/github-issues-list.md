# github-issues-list.png — GitHub Issues 列表页

## 页面用途
GitHub 仓库的 Issues 列表页，查看和管理所有问题。

## 布局结构
左右分栏布局，左侧导航侧边栏，右侧主内容区。

## 主要UI元素
- **左侧边栏**：Issues（当前选中）、Assigned to me、Created by me、Mentioned、Recent activity、Views、Projects、Milestones、Labels
- **搜索框**：含`is:issue state:open`
- **状态筛选标签**：Open 0 / Closed 0
- **筛选下拉菜单**：Author、Labels、Projects、Milestones、Assignees
- **排序选项**：Newest
- **New issue按钮**

## 关键可见文字
All issues、No results、Try adjusting your search filters、New issue
