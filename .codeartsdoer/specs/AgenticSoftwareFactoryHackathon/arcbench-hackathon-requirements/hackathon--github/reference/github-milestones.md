# github-milestones.png — GitHub Milestones 管理页

## 页面用途
GitHub 仓库的 Milestones 管理页，查看和创建里程碑。

## 布局结构
左右分栏布局，左侧导航侧边栏，右侧主内容区。

## 主要UI元素
- **左侧边栏**：Milestones（当前选中，高亮）
- **状态标签**：Open 0 / Closed 0
- **排序选项**：Sort
- **New milestone按钮**
- **空状态提示区**

## 关键可见文字
Milestones、You haven't created any Milestones、Use Milestones to create collections of Issues and Pull Requests、Create a milestone
