# github-new-issue.png — GitHub 新建 Issue 页面

## 页面用途
GitHub 新建 Issue 页面，创建新的问题/任务。

## 布局结构
单栏表单布局，顶部标题，中间表单区，右侧属性设置面板。

## 主要UI元素
- **标题输入框**："Add a title *"（必填）
- **描述编辑区**："Add a description"，含Write/Preview标签、富文本工具栏
- **右侧属性面板**：Assignees（Assign yourself）、Labels（No labels）、Projects（No projects）、Milestone（No milestone）
- **底部按钮**：Create more复选框、Cancel、Create

## 关键可见文字
Create new issue、Title、Type your description here...、Paste, drop, or click to add files、Write with Copilot
