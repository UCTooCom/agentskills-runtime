# github-organization-repositories.png — GitHub 组织仓库列表页

## 页面用途
GitHub 组织/企业的仓库列表页，展示多个公开仓库的汇总信息。

## 布局结构
顶部全局导航 → 左侧筛选边栏 → 主内容区（仓库列表）→ 底部分页器。

## 主要UI元素
- **导航标签**：Overview、Repositories、Projects、Packages、People、Sponsoring
- **筛选选项**：All、Contributed by me、Admin access、Public、Sources、Forks、Archived、Templates
- **列表项**：556个仓库条目，每个含仓库名、描述、标签、语言、统计数、更新时间
- **分页器**：1-19页
- **搜索框**：Search repositories
- **排序下拉**：Last pushed
