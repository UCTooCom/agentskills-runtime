# github-password-reset-1.png — GitHub 修改密码页面

## 页面用途
GitHub 密码重置/修改页面，用于为特定用户账户设置新密码。

## 布局结构
居中卡片式布局，从上到下：GitHub Logo → 标题 → 密码要求说明 → 表单 → 提交按钮。

## 主要UI元素
- **GitHub Logo**
- **标题**："Change password for @anonymous-8H5YnLRXqovD"
- **说明文字**：密码复杂度要求 + "Learn more"链接
- **表单字段**：
  - "Password"标签 + 密码输入框（蓝色聚焦边框）
  - "Confirm password"标签 + 密码确认输入框
- **提交按钮**："Change password"（绿色）
- **页脚**：Terms、Privacy、Docs等

## 颜色样式
- 背景：纯白 #FFFFFF
- 输入框聚焦边框：蓝色 #0969DA
- 提交按钮：绿色 #2DA44E
