# github-password-reset.png — GitHub 密码重置页面

## 页面用途
GitHub 密码重置页面，用户忘记密码时通过邮箱接收密码重置链接。

## 布局结构
居中极简卡片布局，与登录页风格一致。背景纯白色，内容绝对居中。

## 主要UI元素
- **品牌标识**：GitHub Logo
- **页面标题**："Reset your password"
- **说明文字**："Enter your user account's verified email address and we will send you a password reset link."
- **表单字段**："Email"标签 + 邮箱输入框（占位符"Enter your email address"）
- **提交按钮**："Send password reset email"（绿色全宽按钮）
- **页脚**：Terms、Privacy、Docs、Contact GitHub Support、Manage cookies、Do not share my personal information

## 颜色样式
- 背景：纯白 #FFFFFF
- 主按钮：绿色 #2EA44F
- 链接：蓝色 #0969DA
