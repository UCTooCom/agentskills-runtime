# github-pull-requests-list.png — GitHub Pull Requests 列表页

## 页面用途
GitHub 仓库的 Pull Requests 列表页，查看和管理代码合并请求。

## 布局结构
顶部通知栏 + 主内容区。

## 主要UI元素
- **顶部通知横幅**："Label issues and pull requests for new contributors"、Dismiss按钮
- **筛选工具栏**：Filters下拉框、搜索框（`is:pr is:open`）、Labels（9）、Milestones（0）、New pull request按钮
- **主内容区**：空状态提示、ProTip提示

## 关键可见文字
Welcome to pull requests!、Pull requests help you collaborate on code with other people、ProTip! Adding no:label will show everything without a label
