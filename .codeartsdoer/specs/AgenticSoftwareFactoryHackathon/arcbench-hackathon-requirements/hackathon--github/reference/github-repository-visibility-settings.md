# github-repository-visibility-settings.png — GitHub 仓库设置页

## 页面用途
GitHub 仓库设置页，配置仓库各项功能和权限。

## 布局结构
左侧设置导航边栏 → 主内容区（分区块设置表单）。

## 主要UI元素
- **左侧导航**：General、Access、Collaborators、Branches、Tags、Rules、Actions、Webhooks、Pages、Security and quality、Integrations等
- **表单区块**：Repository name、Default branch、Features（Wikis、Issues、Sponsorships、Discussions、Projects、Pull requests）
- **复选框/开关**：各功能启用选项
- **按钮**：Rename、Change visibility、Transfer、Archive this repository、Delete this repository

## 关键可见文字
General、Repository name、first-repo、Default branch、main、Features、Wikis、Issues、Pull requests、Danger Zone、Change repository visibility、Delete this repository
