# github-sign-in.png — GitHub 登录页面

## 页面用途
GitHub 用户登录页面，已注册用户使用用户名/邮箱和密码进行身份验证。

## 布局结构
居中卡片式布局，单列垂直排列。背景纯白色，内容集中在中上部，底部为页脚链接。

## 主要UI元素
- **品牌标识**：GitHub Logo（黑色猫形剪影）
- **页面标题**："Sign in to GitHub"
- **表单字段**：
  - "Username or email address"（文本输入）
  - "Password"（密码输入，右侧附"Forgot password?"链接）
- **主按钮**："Sign in"（绿色背景）
- **第三方登录**："Continue with Google"、"Continue with Apple"按钮
- **分隔线**："or"文字分隔线
- **链接**："Create an account"、"Sign in with a passkey"
- **页脚**：Terms、Privacy、Docs、Contact GitHub Support、Manage cookies、Do not share my personal information

## 颜色样式
- 背景：纯白 #FFFFFF
- 主按钮：GitHub品牌绿 #2EA44F
- 链接：蓝色 #0969DA
- 输入框聚焦边框：蓝色 #0969DA
