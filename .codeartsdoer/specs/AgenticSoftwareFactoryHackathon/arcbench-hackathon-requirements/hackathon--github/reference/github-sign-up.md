# github-sign-up.png — GitHub 注册页面

## 页面用途
GitHub 新账户注册页面，访客通过填写用户名、邮箱、密码创建账户。

## 布局结构
左右分栏式布局：左侧约50%为深色品牌展示区（含3D角色装饰），右侧约50%为浅色表单功能区。

## 主要UI元素
- **左侧品牌区**：主标题"Create your free account"、副标题、下拉链接"See what's included"
- **右侧顶部**：文字"Already have an account?"、链接"Sign in →"
- **表单标题**："Sign up for GitHub"
- **第三方登录**："Continue with Google"按钮、"Continue with Apple"按钮、"— or —"分隔线
- **表单字段**：
  - "Email"（email输入，必填*）
  - "Password"（password输入，必填*，附密码规则说明）
  - "Username"（text输入，必填*，附用户名规则说明）
  - "Your Country/Region"（下拉选择，必填*，默认United Kingdom）
- **复选框**："GitHub Copilot"（附"See terms"链接）、"Email preferences"
- **提交按钮**："Create account >"（绿色背景）
- **底部协议**：含"Terms of Service"、"GitHub Privacy Statement"链接

## 颜色样式
- 左侧背景：深黑→深紫渐变，星空点缀
- 右侧背景：纯白 #FFFFFF
- 提交按钮：GitHub品牌绿 #1F883D
- 链接色：GitHub蓝 #0969DA
- 输入框边框：浅灰 #D0D7DE
