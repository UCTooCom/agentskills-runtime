# github-web-file-editor.png — GitHub 在线文件编辑器

## 页面用途
在线编辑仓库文件内容。

## 布局结构
顶部仓库导航栏 + 左侧文件树 + 右侧编辑器区。编辑器区含文件路径导航、分支标识、编辑/预览标签、代码编辑区域。

## 主要UI元素
- **文件树**：README.md
- **文件路径面包屑**：first-repo / README.md
- **分支标签**：main
- **Edit/Preview标签页**
- **代码编辑框**
- **格式设置**：Spaces/Soft wrap
- **取消/提交按钮**：Cancel changes、Commit changes...

## 关键可见文字
Files、main、README.md、in main、Edit、Preview、# first-repo、Cancel changes、Commit changes...
