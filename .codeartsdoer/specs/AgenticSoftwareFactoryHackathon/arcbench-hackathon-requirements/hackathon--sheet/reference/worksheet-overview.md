# worksheet-overview.png — 电子表格编辑界面

## 页面用途
在线电子表格编辑界面，用于数据录入和计算。

## 布局结构
顶部标题栏 + 菜单栏 + 工具栏 + 公式栏 + 单元格网格区 + 底部工作表标签栏。

## 主要UI元素
- **标题栏**：显示文件名
- **菜单栏**：文件、编辑、查看、插入、格式、数据、工具、扩展程序、帮助
- **常用工具栏**：撤销、重做、打印、格式刷、缩放、货币、百分比、小数位、字体、字号、加粗、斜体、字体颜色、填充颜色、边框、对齐方式、合并单元格、函数等
- **名称框**：A1
- **公式输入框**：fx
- **单元格网格**
- **底部工作表标签**：工作表1
- **共享按钮**
