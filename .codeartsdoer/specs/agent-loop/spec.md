# AgentLoop观测评估飞轮需求规格

## 项目背景

GOAI 2026赛事推荐AgentLoop能力，提供全栈观测、效果评估与自进化调优。本工程实现AgentLoop观测评估飞轮，让Agent系统在真实业务反馈中持续进化。

## 核心问题

1. **缺少全栈观测**: Agent执行全链路无追踪
2. **缺少效果评估**: Agent执行质量无自动评估
3. **缺少自进化调优**: 基于评估结果无自动调整策略
4. **缺少可视化仪表板**: Agent运行状态无实时展示

## 功能需求

### REQ-AL-001: 全栈观测
- Agent执行全链路追踪（请求→决策→工具调用→结果→副作用）
- 与execution-audit工程集成
- 观测数据通过WebSocket实时推送

### REQ-AL-002: 效果评估
- 基于执行证据链自动评估Agent执行质量
- 评估指标：成功率、平均耗时、Token消耗、工具调用次数
- 评估结果持久化到agent_loop_metrics表

### REQ-AL-003: 自进化调优
- 基于评估结果自动调整Agent策略
- 提示词优化、工具选择优化、执行路径优化
- 调优策略可配置

### REQ-AL-004: 可视化仪表板
- Agent运行状态实时展示
- 协作拓扑可视化
- Token消耗统计
- 使用Vue 3 + OpenTiny Vue

## 验收标准

- [ ] Agent执行全链路可追踪
- [ ] 执行质量可自动评估
- [ ] 基于评估结果可自动调整策略
- [ ] 仪表板实时展示Agent运行状态

## 依赖

- 依赖execution-audit工程的执行证据链
