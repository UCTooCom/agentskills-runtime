# **1. 组件定位**

## **1.1 核心职责**

本技能 `beichen-finance-matching` 是运行在 AgentSkills Runtime 上的一个园区金融服务技能，实现北辰命题"金融服务体系化"课题要求的**北辰商管产业金融服务 SOP 全流程线上化**，解决企业"融资难、对接繁、流程慢"三大痛点：

1. **金融工具数据库建设**：构建北辰金融伙伴知识库——超 90 家优质金融合作伙伴（64 家银行、12 家证券、9 家基金、6 家投资公司），沉淀超 200 家次企业金融服务经验（命题原文："开放金融工具数据库，供开发金融匹配智能体"）
2. **企业融资需求采集与初步审核**：收集企业基本信息、融资需求（金额/期限/用途）、初步筛选（对应 SOP 阶段一"资料提交与审核，1 个工作日"）
3. **需求匹配优势金融机构**：根据需求智能匹配金融伙伴库中的优势机构与产品（对应 SOP 阶段二"方案制定与洽谈"），输出定制金融方案
4. **金融机构对接**：协助企业与匹配机构对接、洽谈细节（生成对接材料包，对应 SOP 阶段三"金融机构对接，2 个工作日"）
5. **落地执行跟踪**：执行方案双方审核、实时跟进（对应 SOP 阶段四"落地执行，3-5 个工作日"）
6. **服务闭环**：完成服务、定期回访维护（对应 SOP 阶段五"服务闭环，约定时限→长期"），全流程责任到人、进度可视
7. **结果落库与呈现**：企业信息写入 `company` 表，融资方案与服务任务写入 `tasks` 表，复用 aibuilder 模块呈现

## **1.2 核心输入**

1. **企业融资需求**：企业名称、融资金额、期限、用途（流动资金/研发投入/设备采购/股权融资等）、可接受担保方式、财务概况
2. **金融伙伴目录**：命题提供的 90+ 家金融合作伙伴（64 银行 / 12 证券 / 9 基金 / 6 投资公司），作为金融工具数据库种子数据
3. **金融产品资料**：各伙伴机构的产品要素（贷款/贴息/担保/股权投资/上市辅导等，可由公开资料与运营方持续补充）
4. **大模型服务**：asr 配置的大模型（昇腾 API / AtomGit，OpenAI 兼容接口）
5. **数据库**：runtime 连接的 PostgreSQL 数据库（company / tasks 表，复用现有结构）

## **1.3 核心输出**

1. **金融工具数据库**：结构化金融伙伴与产品库（`knowledge/finance-partners/` + `finance-index.json`）
2. **融资需求档案**：企业融资需求结构化 JSON（`output/needs/`）
3. **匹配结果**：需求 × 金融机构/产品匹配矩阵（`output/matches/`）
4. **定制金融方案**：融资方案 Markdown（含 2-3 个备选机构方案、利率/期限/担保对比、对接路径）（`output/plans/`）
5. **对接材料包**：金融机构对接所需材料清单与预填信息（`output/dossiers/`）
6. **服务跟踪流水**：SOP 六阶段进度流水（`output/tracking/`）
7. **落库 SQL / 数据库记录**：company 表 upsert + tasks 表融资方案与服务任务（aibuilder 可呈现）

## **1.4 职责边界**

本技能**不负责**以下事项：

- **不开发仓颉程序**：本次参赛只开发 Skill（SKILL.md + scripts），不做 runtime 仓颉代码修改
- **不做数据库结构变更**：复用现有 company / tasks 表结构
- **不替代金融机构审批**：技能输出匹配建议与方案草稿，融资可行性、利率与放款由金融机构独立审批决定
- **不直接对接金融机构内部系统**：对接动作以生成材料包 + 人工/运营方推进为主（SOP 中"协助企业提交资料金融机构"由运营方完成）
- **不提供投资建议**：方案仅供融资决策参考（合规要求）
- **不使用非公开数据**：仅使用命题提供的伙伴目录与公开产品资料

# **2. 顶层设计原则**

## **2.1 原则 1：最大化复用产品体系已有能力**

| 产品能力 | 复用方式 |
|---------|---------|
| AgentSkills Runtime v0.0.27 | 技能运行环境、内置工具（web_fetch/http_request/web_search/cli_execute）、插件系统 |
| 大模型服务 | 昇腾 API（AtomGit，OpenAI 兼容），通过 `.env` 配置切换 |
| company / tasks 表 + aibuilder | 企业与融资任务呈现模块 |
| WebMCP 通道 | 企业用户自然语言提交融资需求、查询匹配进度（供需对接官网子系统内嵌） |
| RBAC 权限体系 + 审计日志 | 安全合规 |
| fintech-agent-hackathon 智能投研助理 | 六步 SOP 流程范式、company/tasks 落库模式 |
| 产业政策技能（beichen-policy-assistant） | 企业画像互认（金融画像可直接复用政策技能画像，反之亦然） |

## **2.2 原则 2：SOP 时效承诺内建（命题核心要求）**

北辰金融 SOP 的时效承诺（资料审核 1 个工作日 → 方案制定 1 个工作日 → 机构对接 2 个工作日 → 落地执行 3-5 个工作日 → 服务闭环约定时限）作为流程元数据内建于任务流转，每个服务任务自动计算各阶段截止时间，超期自动标记提醒，让"流程慢"可度量、可追责。

## **2.3 原则 3：全链路国产自主可控**

仓颉 Runtime + 昇腾算力（API）+ 国产数据库，满足园区数字化服务的信创要求。

## **2.4 原则 4：确定性优先**

匹配规则可解释（每条匹配给出机构类型、产品要素与需求的对应关系）、过程可追溯（output 目录全量持久化）、结论可复核（方案标注数据来源与假设条件）。

# **3. 领域术语**

**金融匹配技能（beichen-finance-matching）**
: 实现北辰商管产业金融服务 SOP 全流程线上化的 Agent 技能（Skill），本次参赛核心开发件之一。依托 asr 插件系统可实例化为"北辰金融匹配智能体"。

**金融工具数据库（Finance Tool Database）**
: 90+ 家金融合作伙伴及其产品的结构化知识库（机构类型、优势领域、产品要素、服务经验），命题方开放供开发金融匹配智能体使用。

**北辰金融 SOP**
: 命题定义的产业金融服务流程：资料提交与审核（1 工作日）→ 方案制定与洽谈（1 工作日）→ 金融机构对接（2 工作日）→ 落地执行（3-5 工作日）→ 服务闭环（约定时限→长期），配三大保障原则（精准高效对接 / 专属全程辅导 / 标准前置管控）。

**金融伙伴（Finance Partner）**
: 北辰生态的金融机构伙伴，分银行、证券、基金、投资公司四类（64/12/9/6 家）。

**融资需求档案（Financing Need）**
: 企业提交的结构化融资需求（金额、期限、用途、担保方式、财务概况）。

**匹配矩阵（Matching Matrix）**
: 融资需求 × 金融产品/机构的多维匹配结果（匹配度评分、匹配依据、机构优势项）。

**对接材料包（Dossier）**
: 协助企业向匹配金融机构提交资料的清单与预填信息集合。

**AgentSkills / SKILL.md**
: 开放标准技能格式，runtime 加载执行的技能单元。

**aibuilder**
: runtime 中的 AI Builder 模块（web-admin 前端），呈现 company 列表与 tasks 详情。

**昇腾 AI 算力底座**
: 国产算力生态。本作品通过 AtomGit 昇腾 API（OpenAI 兼容接口）接入。

# **4. 角色与边界**

## **4.1 核心角色**

- **园区运营人员（北辰商管金融业务同事）**：维护金融伙伴库、复核匹配方案、推进机构对接与落地执行
- **入驻企业用户**：提交融资需求、获取定制金融方案、查看对接进度（WebMCP / 官网）
- **金融机构伙伴**：接收对接材料、独立审批、反馈方案（线下/运营方中转）
- **Agent 技能**：自动执行需求建档→匹配→方案→材料包→跟踪→落库全流程
- **评审专家**：检验可运行性、业务闭环、技术创新性

## **4.2 外部系统**

- **AgentSkills Runtime**：技能运行环境，提供内置工具与大模型调用
- **昇腾 API（AtomGit）**：大模型算力底座
- **PostgreSQL**：company / tasks 表存储
- **公开金融产品资料**：机构官网、公开产品说明（合规补充）

# **5. 核心能力**

## **5.1 金融工具数据库建设（Finance KB）**

- 以命题 90+ 家伙伴目录为种子（机构名称、类型：银行/证券/基金/投资公司、数量 64/12/9/6）
- 产品要素结构化：产品类型（信贷/贴息/担保/股权投资/债券承销/上市辅导）、额度范围、期限、担保要求、目标客群、优势领域
- 服务经验沉淀：200+ 家次企业服务案例要点（脱敏），持续积累匹配先验
- 通过 `scripts/init_finance_kb.py` 初始化 + `knowledge/` 目录文件化管理

## **5.2 融资需求采集与初步审核（Intake）**

- 结构化采集：企业信息（可复用产业政策技能画像）、融资金额/期限/用途、担保方式、财务概况（营收/负债粗粒度）
- 初步审核：需求完整性校验、基本可行性初判（金额与规模匹配度、用途合理性）、缺失项提示
- 对应 SOP 阶段一（1 个工作日时效）
- 通过 `scripts/collect_financing_need.py` 实现

## **5.3 需求匹配优势金融机构（Match）**

- 硬性条件初筛：额度/期限/担保方式与产品要素对标，不满足硬条件的淘汰
- 优势匹配：需求领域 × 机构优势领域（如 AI 企业研发贷 → 有科技金融专项的银行）、服务经验先验加权
- 输出匹配矩阵（机构、产品、匹配度评分、匹配依据、机构优势项），Top 2-3 家进入方案
- 通过 `scripts/match_finance.py` 实现

## **5.4 定制金融方案生成（Plan）**

- 调用大模型（昇腾 API）生成定制方案：2-3 个备选机构方案对比（额度/利率区间/期限/担保/放款周期）、适配理由、风险提示
- 未配置 LLM 时降级为模板生成（矩阵直出对比表）
- 对应 SOP 阶段二（1 个工作日时效）
- 通过 `scripts/generate_finance_plan.py` 实现

## **5.5 对接材料包生成（Dossier）**

- 按目标机构常见资料清单生成核对清单（营业执照、财报、纳税记录、经营流水、用途说明等）
- 预填需求档案已有信息，标注缺失材料与获取路径
- 对应 SOP 阶段三（2 个工作日时效，协助企业提交资料金融机构）
- 通过 `scripts/build_dossier.py` 实现

## **5.6 落地执行与服务闭环跟踪（Track）**

- SOP 六阶段任务流水：每个融资服务任务记录当前阶段、阶段截止时间（按 SOP 时效自动计算）、责任人、状态
- 超期自动标记（SOP 时效承诺可度量），阶段推进留痕
- 回访提醒：服务完成后按周期生成回访任务（对应"定期回访维护、长期"）
- 通过 `scripts/track_service.py` 实现

## **5.7 结果落库与呈现（Persist & Present）**

- company 表 upsert（企业信息 + 融资需求摘要）
- tasks 表插入融资方案（task_type='finance-plan'）与阶段服务任务（task_type='finance-service'，含 SOP 阶段与截止时间）
- aibuilder 模块呈现：企业列表 → 融资方案 → 服务进度

# **6. 数据约束**

## **6.1 知识库文件结构（本技能新增）**

```
knowledge/
├── finance-partners/        # 金融伙伴库（90+ 家，按类型分文件）
│   ├── banks.json           # 64 家银行
│   ├── securities.json      # 12 家证券
│   ├── funds.json           # 9 家基金
│   └── investors.json       # 6 家投资公司
├── finance-products/        # 产品要素库（{机构}-{产品}.md）
├── finance-experience/      # 服务经验案例要点（脱敏）
└── finance-index.json       # 总索引（机构/类型/优势领域/产品数）
```

## **6.2 company 表（复用现有结构）**

| 字段 | 说明 |
|------|------|
| company_name | 企业名称（upsert 去重键） |
| region | 注册区域（如"北京市朝阳区"） |
| org_description | 企业与融资需求摘要 |
| org_type | 'beichen-enterprise'（与产业政策技能共用） |
| is_verified | false |

## **6.3 tasks 表（复用现有结构）**

| 字段 | 说明 |
|------|------|
| title | 融资方案 - {企业名称} / {阶段名} - {企业名称} |
| description | 方案正文（Markdown）/ 阶段任务说明 |
| task_type | 'finance-plan' / 'finance-service' |
| task_status | 'completed'（方案）/ 'pending'→'in-progress'→'completed'（阶段任务） |
| company_id | 关联 company 表 id |
| tags | ["beichen","finance-plan"] / ["beichen","finance-service"] |
| extra_data | sop_stage（1-6）、due_date（阶段截止）、amount、partners（候选机构） |
