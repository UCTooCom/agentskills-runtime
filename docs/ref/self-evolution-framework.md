# 开发框架自主进化

## 概述

本框架描述了以 AgentSkills-runtime 为核心的自主进化开发体系。通过主线版本开源社区维护升级迭代与个性化开发代码不被覆盖的有机合并，形成数字世界的分布式自主进化开发框架。

## 核心组件

### 1. AgentSkills-runtime

**定位**：整个自主进化体系的核心运行时

**关键特性**：
- 支持 AgentSkills 标准的开发框架
- 驱动 skill-creator 运行
- 主线版本开源社区维护升级迭代
- 个性化开发代码不被覆盖，有机合并
- 数字世界的分布式自主进化开发框架

---

### 2. skill-creator

**定位**：技能创建与分发引擎

**关键特性**：
- 生成更多总结了 SOP 的 markdown 技能
- 通过技能市场在数字世界分发

---

### 3. Cangjie-coder / CangjieSkills

**定位**：高质量代码与工具生成器

**关键特性**：
- 重构 CaqnjieSkills 技能 1.0.0 版本
- 通用化适配各种 IDE
- CodeArts Agent 实测良好
- 通过各种 AgentSkills 生成高质量的代码和工具

---

### 4. crudgen CLI / Remote API

**定位**：代码、文档与数据库循环迭代工具

**关键特性**：
- 将各种高质量代码和工具通过 AgentSkills 组合使用
- 代码 + 文档 + 数据库循环迭代
- 工具创建更强大的工具

---

### 5. Crud-generator skill

**定位**：代码生成技能

**关键特性**：
- 将各种高质量代码和工具通过 AgentSkills 组合使用
- 为主线版本开源社区维护升级迭代提供支持

## 进化闭环

整个框架形成一个完整的自主进化闭环：

```
AgentSkills-runtime
        ↓
   skill-creator          →  生成 SOP 技能，通过技能市场分发
        ↓
Cangjie-coder/CangjieSkills  →  重构技能，适配各种 IDE
        ↓
  crudgen CLI / Remote API    →  代码+文档+数据库循环迭代
        ↓
  Crud-generator skill        →  组合使用高质量代码和工具
        ↓
AgentSkills-runtime          →  回到核心，完成闭环
```

## 核心价值

1. **自主进化**：框架能够自我迭代、自我完善，形成正向循环
2. **分布式协作**：数字世界中分布式的自主进化开发框架
3. **技能市场**：通过技能市场实现知识和能力的分发与共享
4. **代码质量保证**：Cangjie-coder 生成高质量代码，实测验证
5. **有机合并**：主线版本与个性化开发有机合并，互不覆盖
