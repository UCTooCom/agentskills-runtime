关于 AgentSkills Runtime

AgentSkills Runtime 是 AI 代理技能的运行环境，提供：

  • AI 模型集成：支持多种主流 AI 模型提供商
    • StepFun (阶跃星辰)：step-1-8k, step-1-32k 等模型
    • DeepSeek：deepseek-chat, deepseek-coder 等模型
    • Sophnet：MiniMax-M2.5 等模型
    • 华为云 MaaS：qwen3-coder-480b-a35b-instruct 等模型
    • OpenAI：gpt-4, gpt-3.5-turbo 等模型
    • 智谱 AI (ZhipuAI)：glm-4, glm-3-turbo 等模型
    • 阿里云 DashScope：qwen-turbo, qwen-plus 等模型
    • SiliconFlow：多种开源模型
    • Google Gemini：gemini-pro 等模型
    • Moonshot (月之暗面)：moonshot-v1-8k 等模型
    • 火山引擎 ARK：字节跳动大模型服务
    • OpenRouter：统一接入多种模型
    • Ollama：本地部署的开源模型
    • LLama.cpp：本地推理服务
  • 技能管理和执行：安装、运行和管理 AI 技能
  • 自然语言处理能力：文本生成、嵌入、图像生成
  • 跨平台支持：Windows、macOS、Linux
  • 技能搜索：支持 GitHub、Gitee、AtomGit 仓库搜索
  • 网络搜索：集成 Firecrawl 进行网络内容抓取

PostgreSQL 未安装

请按照以下步骤安装 PostgreSQL：

  1. 下载 PostgreSQL
    访问官方网站：https://www.postgresql.org/download/
    选择适合您操作系统的版本（推荐 PostgreSQL 14 或更高版本）
  2. 安装 PostgreSQL
    Windows: 下载安装程序并运行
    macOS: 使用 Homebrew: brew install postgresql@14
    Linux: 使用包管理器: sudo apt-get install postgresql-14
  3. 初始化数据库
    安装完成后，PostgreSQL 会自动创建默认数据库和用户
    默认用户: postgres
    默认端口: 5432
  4. 创建数据库
    使用 pgAdmin 或命令行创建数据库：
    CREATE DATABASE uctoo;
