# X25519 API 参考

## 常量

| 常量 | 值 | 说明 |
|------|-----|------|
| `CONTRACT_X25519_KEY_LEN` | 32 | X25519 密钥长度 |
| `CONTRACT_X25519_SHARED_SECRET_LEN` | 32 | 共享密钥长度 |
| `CONTRACT_X25519_ALGORITHM` | `"X25519"` | 算法标识 |

## 类型

### ContractX25519KeyPair
`privateKey: Array<Byte>`, `publicKey: Array<Byte>`（各 32 字节）

### ContractX25519KeyAgreementRequest
`privateKey: Array<Byte>`, `peerPublicKey: Array<Byte>`（各 32 字节）

### ContractX25519KeyAgreementResult
`algorithm: String`, `publicKey: Array<Byte>`, `sharedSecret: Array<Byte>`

### ContractX25519KeyAgreementOutcome
`ok: Bool`, `message: String`, `code: ?ContractErrorCode`, `igniteCode: ?ContractIgniteCryptoErrorCode`, `result: ?ContractX25519KeyAgreementResult`

## 函数

### contractX25519GenerateKeyPair(): ContractX25519KeyPair
生成随机密钥对。私钥自动 clamp。

### contractX25519ClampPrivateKey(privateKey): Array<Byte>
对私钥进行 X25519 clamp 操作。

### contractX25519PublicFromPrivate(privateKey): Array<Byte>
从私钥推导公钥。

### contractX25519DeriveKeyAgreement(request): ContractX25519KeyAgreementResult
### contractX25519DeriveKeyAgreement(privateKey, peerPublicKey): ContractX25519KeyAgreementResult
派生共享密钥。错误时抛出 `ContractException`。

### contractTryX25519DeriveKeyAgreement(request): ContractX25519KeyAgreementOutcome
### contractTryX25519DeriveKeyAgreement(privateKey, peerPublicKey): ContractX25519KeyAgreementOutcome
安全的错误处理版本，返回 `Outcome` 而非抛出异常。

## 错误码

- `BAD_INPUT`：密钥长度不为 32 字节或共享密钥全零
