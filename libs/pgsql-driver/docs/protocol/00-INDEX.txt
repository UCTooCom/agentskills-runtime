实现建议（postgre_driver）
--------------------------------------------------------------------------------
最小可用客户端实现顺序：
  1. 54.6 数据类型  -> 编解码原语（大端整数、C 字符串、定长字节）
  2. 54.7 消息格式  -> StartupMessage / Query / 各响应报文的字节布局
  3. 54.2 消息流    -> 连接启动、简单查询、扩展查询的状态机
  4. 54.3 SASL      -> SCRAM-SHA-256（现代 PostgreSQL 默认认证方式）
