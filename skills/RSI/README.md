# RSI —— ASR 自进化系统技能

> 把《人工智能软件工程方法论》从理论到实践落地的执行中枢。
> 配套 SDD：`specs/RSI/{research,spec,design,tasks}.md`

## 它解决什么问题

开发框架要"在运行中持续进化"，但有一个被业界长期忽略的硬约束：

> **用含概率的大模型直接生成"全部框架源码"是错配**——框架代码是确定性软件，
> 一线实测"加一个字段都改不对、必经编译失败—修复循环"，达不到框架级进化要求。

ASR 的解法：让 **AI 当脑（规划与编排）**、让 **开发框架当手（确定性代码生成工具）**。
这就是 RSI 的全部——**代码 + 技能 + 数据库**三大基础设施的闭环自进化。

## 核心铁律

**RSI-0：框架级确定性优先由确定性代码生成工具保障，以系统工程的确定性消解 LLM 的不确定性；LLM 仍在需要的流程与位置生成代码，只是不再让其概率性输出单独承担框架级结构正确性（不是"去 LLM"，而是让合适的子系统特性由合适的组件提供）。**

## 五阶段循环（心跳）

```
实测 → 根因 → 优化方案 → 防回退 → 约束注入  （周期/事件触发，由 LRT 调度）
```

## 三腿闭环

```
schema → (UMI/UMI-ORM) → ORM+CRUD → (crudweb) → Web/App → (SKILL.md) → LLM Tool → 规划下一轮
```

## 端到端演示：新增"低代码表单引擎"

| 步 | 谁做 | 动作 |
|---|---|---|
| 1 规划 | 脑(LLM) | 解析目标，选 `loaddbinfo→plugingen→crudgen→crudweb` |
| 2 生成 | 手(工具) | 确定性产出插件 + 界面骨架（编译可用） |
| 3 治理 | 闸口 | 转 SDD 工程，附防回退锚点，过 gate-* |
| 4 验证 | 护栏 | build watcher 绿 + 测试过 → git 入库 |
| 5 暴露 | 原生智能 | form-engine 经"一切皆技能"自动进 LLM 可见列表 |
| 6 循环 | 脑(LLM) | 基于新能力规划下一轮（如"加权限字段"） |

整个过程 **LLM 零裸写框架源码**。

## 复用的基础设施

确定性工具 `loaddbinfo/crudgen/crudweb/plugingen/pluginuninstall` · SDD 流水线 · 多技能并行 `src/skill/parallel` ·
LRT 长程任务 · 一切皆技能 · UMI 数据架构 · `docs/uctoo-v4` 规范。

## 与同业差异（一句话）

同业把自进化停在"技能文本层"且缺确定性代码生成；ASR 推进到"确定性工具驱动的源码层 + 技能层 + DB 层"，
并且**架构不腐坏、对二次开发友好**——这是 AI 驱动开发框架超越 harness 的根基。

## 落地分期

- **P0**：本技能 + RSI-0 护栏 + 复用 SDD/LRT/parallel 跑通代码腿与技能腿。
- **P1**：补全 UMI-ORM DB 腿（C4 升级为全能力）。
- **P2**：防回退锚点固化、验证强制链、开放标准 `self-evolution` 声明、周期/事件心跳。
