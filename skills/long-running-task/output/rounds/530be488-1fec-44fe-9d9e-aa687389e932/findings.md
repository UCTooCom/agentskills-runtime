- 卷别：2025 年北京卷（北京教育考试院学考等级考）
- 题号：第 20 题（压轴题，3 问）
- 背景：静电除尘器 / 金属圆筒与轴线金属丝电极
- 已获第(1)问近似原文：
  > 如图1所示，金属圆筒 A 接高压电源的正极，其轴线上的金属线 B 接负极。(1) 设 A、B 两极间电压为 U，求在 B 极附近电荷量为 q 的负电荷到达 A 极过程中静电力做的功 W。

- 来源：360 搜索 / ai.so.com / 豆丁网 / 学科网 / 无忧考网等摘要
