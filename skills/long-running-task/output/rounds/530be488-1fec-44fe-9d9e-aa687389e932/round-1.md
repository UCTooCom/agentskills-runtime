**20．** 金属圆筒 A 接高压电源正极，轴线上金属线 B 接负极，A、B 间电压 U，筒内为轴对称辐向电场。
(1) 电荷量 q 的负电荷从 B 极附近到达 A 极，求静电力做的功 W；
(2) 筒内距轴线 r 处场强 E = 2kλ/r，求带电粒子（电荷量 q、质量 m）绕轴做匀速圆周运动的速率 v 与半径 r 的关系及动能关系；
(3) 类比氢原子：基态轨道半径 a₀ = 5.3×10⁻¹¹ m，电离能 |E₁| = 13.6 eV，电子沿径向最大可移动约 2a₀，求恰使基态氢原子电离所需外电场场强最小值 E₀。

### 三、独立解答全文（要点）
- **第(1)问**：负电荷 −q 从低电势（B）到高电势（A），W = (−q)(φ_B − φ_A) = (−q)(−U) = **qU（正功）**；并用"B 排斥、A 吸引，合力沿 B→A"作受力方向校验。
- **第(2)问**：qE = mv²/r，代入 E = 2kλ/r 后 r 被约去，得 **v = √(2kλq/m)、E_k = kλq，均与半径 r 无关**；指出根源是 1/r 型辐向场中静电力与所需向心力对 r 的依赖相同。
- **第(3)问**：能量观点，eE₀·2a₀ = |E₁| ⟹ **E₀ = |E₁|/(2ea₀) ≈ 1.29×10¹¹ ≈ 1.3×10¹¹ V/m**；并作量级检验——远高于空气击穿场强（~3×10⁶ V/m），说明纯静电场电离孤立原子极难实现。
