## 二、题干（据公开信息重建）

**20．** 静电除尘器可去除烟气中的粉尘。一只金属圆筒 A 接高压电源的**正极**，位于圆筒轴线上的金属线（金属丝）B 接高压电源的**负极**。设 A、B 两极间电压为 *U*。圆筒内部形成以轴线为中心的**轴对称辐向电场**（忽略端部效应）。

**(1)** 设 A、B 两极间电压为 *U*，一电荷量为 *q* 的**负**电荷从 B 极附近到达 A 极，求此过程中**静电力做的功** *W*。

**(2)** 筒内距轴线 *r* 处的电场强度大小 *E* 与 *r* 的关系为 *E* = 2*kλ*/*r*（*k* 为静电力常量，*λ* 为金属线 B 单位长度电荷量）。一带电粒子在筒内以半径 *r* 绕轴线做**匀速圆周运动**，求其**速率** *v* 与半径 *r* 的关系，并说明动能与半径的关系。

**(3)** 将上述模型类比到氢原子：核外电子绕核做圆周运动，基态轨道半径 *a*₀ = 5.3×10⁻¹¹ m，基态电离能 |*E*₁| = 13.6 eV。若把氢原子置于沿径向的匀强外电场 *E*₀ 中，电子沿电场方向最多可移动约 2*a*₀ 而未脱离束缚，求**恰能使基态氢原子电离**所需外电场场强的最小值 *E*₀（保留两位有效数字）。

---

## 三、已知条件

- *U*：A、B 两极间电压（A 正、B 负，故 φ_A > φ_B）；
- 负电荷电荷量 −*q*（*q* > 0）；
- 辐向场强 *E*(*r*) = 2*kλ*/*r*，*k* = 9.0×10⁹ N·m²/C²，*λ* 已知；
- 圆周运动粒子：电荷量 *q*、质量 *m*；
- *a*₀ = 5.3×10⁻¹¹ m；|*E*₁| = 13.6 eV = 2.18×10⁻¹⁸ J；*e* = 1.6×10⁻¹⁹ C。

---

## 四、解题思路

1. **(1) 功能的电势观点**：静电力做功与路径无关，*W* = *q*_c(φ_初 − φ_末)。负电荷 + A 电势高于 B，两个负号相消 → 正功。
2. **(2) 动力学 + 对称性**：向心力由静电力提供，*qE* = *mv*²/*r*；代入 *E* = 2*kλ*/*r* 后 *r* 被约去 → *v* 与 *r* 无关。
3. **(3) 能量观点**：电离需外界提供 |*E*₁|，来源是电场力做功；最大有效位移 ≈ 2*a*₀，故 *eE*₀·2*a*₀ = |*E*₁|。

## 五、推导过程

### 第 (1) 问　静电力做的功

设 φ_A − φ_B = *U*（A 接正极，B 接负极）。负电荷电荷量记为 *q*_c = −*q*。

静电力做功通式：

    W = q_c (φ_初 − φ_末) = (−q)(φ_B − φ_A) = (−q)(−U) = qU

**物理校验**：B（负）排斥负电荷，A（正）吸引负电荷，合力均沿 B→A，与位移同向 → 做正功，与 *W* = *qU* > 0 一致。

> **结论：W = qU**（正功）。

### 第 (2) 问　辐向电场中的匀速圆周运动

向心力：

    qE(r) = m v² / r

代入 *E*(*r*) = 2*kλ*/*r*：

    q · (2kλ/r) = m v² / r  ⟹  2kλq = m v²

故

    v = √(2kλq / m)      （与 r 无关）
    E_k = ½mv² = kλq       （与 r 无关）

**物理意义**：1/*r* 型辐向场中，静电力 *qE* ∝ 1/*r*，圆周运动所需向心力 *mv*²/*r* ∝ 1/*r*，对 *r* 的依赖相同，故任一半径都可用同一速率维持圆周运动。

> **结论：v = √(2kλq/m)，E_k = kλq；二者均与半径 r 无关。**

### 第 (3) 问　使基态氢原子电离的最小外电场

电场力对电子最大做功：

    W_max = eE₀ · 2a₀

恰能电离的临界条件：

    eE₀ · 2a₀ = |E₁|

    ⟹  E₀ = |E₁| / (2 e a₀)

数值代入：

    |E₁| = 13.6 eV = 13.6 × 1.6×10⁻¹⁹ J = 2.18×10⁻¹⁸ J
    e a₀ = 1.6×10⁻¹⁹ × 5.3×10⁻¹¹ = 8.48×10⁻³⁰ C·m
    2 e a₀ = 1.696×10⁻²⁹ C·m

    E₀ = 2.18×10⁻¹⁸ / 1.696×10⁻²⁹ ≈ 1.29×10¹¹ N/C ≈ 1.3×10¹¹ V/m

> **结论：E₀ = |E₁|/(2ea₀) ≈ 1.3×10¹¹ V/m。**

## 七、结果与讨论

1. **第(1)问的“双重负号”**：负电荷从低电势到高电势，电势能减小、静电力做正功。漏掉“电荷为负”或“A 电势高于 B”任一项都会得到错误结论；用“同号排斥异号吸引”判断受力方向最稳妥。
2. **第(2)问的对称性**：1/*r* 型辐向场中圆周运动速率与半径无关，说明同心圆筒结构下不同半径处的带电粒子均可同一速率运动——正是静电除尘器可做成同心圆筒结构的物理原因。
3. **第(3)问的量级检验**：*E*₀ ≈ 1.3×10¹¹ V/m 远高于空气击穿场强（~3×10⁶ V/m），说明纯静电场电离孤立原子极难实现，真实电离需火花放电/光电离等机制；该结果与公开讨论的量级互相印证。
