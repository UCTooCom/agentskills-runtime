    • 本科是什么学位 本科学历和学士学位有什么不同

      李婷婷：

      本科不是学位里的。
      本科属于学历。学历分为中专、大专、本科、研究生。
      学位分为学士、硕士、博士。
      对于本科学历学生来说，毕业时成绩达到要求，可以拿到学士学位，如果成绩达不到要求，只有本科学历，没有学士学位。
      研究生分硕士学位和博士学位。

    • 黄冈中学为什么出名

      张晴：

      对于黄冈中学，大多数70后、80后应该是无人不知，无人不晓。

      黄冈中学坐落在大别山南麓的黄州古城，创建于1904年。初创时期，董必武同志曾在校执教并任校董事。

      然而，黄冈中学为什么这么出名呢？这个问题应该和黄冈中学当年的成绩有关。当年改革开放初期，中国刚刚走出国门，教育的国际化也刚刚起步，然而，就是这么一个中学，在每年的国际大赛上屡屡得奖，而且屡屡包揽金银铜前三名。

    • 平面设计主要做什么

      宋振浩：

      其实平面设计由三个要素构成，首先是创意、其次是构图，最后是色彩。

      创意：是平面设计的第一要素，没有好的创意，就没有好的作品，创意中要考虑观众、传播媒体、文化背景三个条件。

      构图：构图就是要解决图形、色彩和文字三者之间的空间关系，做到新颖，合理和统一。

      色彩：好的平面设计作品在画面色彩的运用上注意调和、对比、平衡、节奏与韵律。

    • 本科是什么学位 本科学历和学士学位有什么不同

      李婷婷：

      本科不是学位里的。
      本科属于学历。学历分为中专、大专、本科、研究生。
      学位分为学士、硕士、博士。
      对于本科学历学生来说，毕业时成绩达到要求，可以拿到学士学位，如果成绩达不到要求，只有本科学历，没有学士学位。
