## 2. 数量级

## 3. 极限 / 趋势

- (1) q→0 ⟹ W→0；U 反向 ⟹ W 反号。
- (2) λ→0 ⟹ v→0；结论“v 与 r 无关”依赖 E∝1/r，若 E∝1/r² 则 v∝1/√r（不再独立于 r）。

## 4. 交叉验证

- (2) 辐向力为辏力，对圆周运动不做功 ⟹ 速率/动能守恒，与“v 与 r 无关”一致。
