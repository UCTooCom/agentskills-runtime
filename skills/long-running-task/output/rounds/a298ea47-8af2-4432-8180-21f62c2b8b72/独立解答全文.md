## 二、题干（重建）

20．静电除尘器中金属圆筒 A 接正极、轴线金属线 B 接负极，两极间电压 U，形成轴对称辐向电场。

(1) 负电荷 q 从 B 到 A，求静电力做功 W。

(2) 筒内 E = 2kλ/r；带电粒子（q, m）以半径 r 绕轴匀速圆周运动，求 v 与 r 的关系及动能与 r 的关系。

(3) 类比氢原子：a₀ = 5.3×10⁻¹¹ m，电离能 |E₁| = 13.6 eV。外电场沿径向，电子最多移动约 2a₀，求恰能电离所需外电场最小值 E₀（两位有效数字）。

## 三、解答

### 第 (1) 问

W = q_c(φ_B − φ_A) = (−q)(−U) = **qU**（正功）。

受力校验：B 排斥、A 吸引，合力沿 B→A，做正功，自洽。

### 第 (2) 问

qE(r) = mv²/r，E = 2kλ/r

→ q·2kλ/r = mv²/r → 2kλq = mv²

→ **v = √(2kλq/m)**（与 r 无关）；**Eₖ = ½mv² = kλq**（与 r 无关）。

### 第 (3) 问

eE₀·2a₀ = |E₁| → E₀ = |E₁|/(2ea₀)

利用 |E₁| = 13.6 eV = 13.6e：

E₀ = 13.6 V / (2 × 5.3×10⁻¹¹ m) ≈ **1.28×10¹¹ V/m ≈ 1.3×10¹¹ V/m**。

## 四、答案汇总

| 小问 | 表达式 | 结论 |
|---|---|---|
| (1) | W = qU | 正功 |
| (2) | v = √(2kλq/m)，Eₖ = kλq | 均与 r 无关 |
| (3) | E₀ = |E₁|/(2ea₀) | ≈ 1.3×10¹¹ V/m |

## 五、自我验核

- 量纲：C·V = J ✓；√(J/kg) = m/s ✓；J/(C·m) = V/m ✓
- 量级：E₀ ~ 10¹¹ V/m ≫ 空气击穿 3×10⁶ V/m，与“静电电离极难”的常识自洽
- 极限：q→0 则 W→0；λ→0 则 v→0；a₀→∞ 则 E₀→0
- 交叉：辏力不做功 → v 恒定（动能守恒）；E₀ 用 13.6e 相消与逐步代入结果一致（1.28~1.29×10¹¹ V/m）
