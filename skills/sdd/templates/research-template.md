# 研究文档模板（Research Template）

> 用途：规范驱动开发（SDD）流程的**第 1 步（研究，可选）**产出模板。
> 研究是开放自由的工作流，没有强制格式；本模板提炼自 `long-running-task/research.md` 与 AI 驱动开发框架的最佳实践，作为后续 SDD 研究步骤的统一骨架。
> 落盘位置：**runtime 自有 `specs/<feature-name>/research.md`**（相对 runtime 根，如 `apps/agentskills-runtime/specs/<feature-name>/`）；**禁止**落到 `.codeartsdoer/specs/`（该目录归属 CodeArts Agent）。
> 使用方式：复制本模板，替换 `[方括号占位]` 与示例内容，删除不适用的小节。

## 编写要点（写给执行研究步的子 agent）

1. **先盘后建**：研究阶段只做"盘点 + 缺口 + 推荐方案"，不要在这个阶段写实现代码或最终规格；那是 spec/design 的事。
2. **原文引用优先**：涉及用户约束、既有文档结论时，保留原文而非转述，避免失真。
3. **复用优先，新建最小化**：每一条"待建"都要先问"已有基础设施能不能只加配置/数据就满足"，能复用就复用。
4. **给出可执行的下一步**：研究文档的结尾必须能直接喂给 spec 阶段，列出要固化的需求项。
5. **诚实标注未知**：没有查实的信息标注"待核实"，不要用猜测填充确定性结论。
