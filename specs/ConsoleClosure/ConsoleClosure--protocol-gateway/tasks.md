## 开发规范（全任务强制遵守）
- **语言与工具绑定**：仓颉 → cangjie-coder（AI 不运行 `cjpm build`，编译由人工回传）；前端 → web-coder；勘查/集成验证 → 主 agent。
- **二次开发底座优先（铁律 14）**：迭代 runtime 时先加载 `uctoo-dev-manual`（`skills/uctoo-dev-manual/`），按 `docs/uctoo-v4/*.md` 对齐；脚手架优先 `loaddbinfo` → `plugingen`/`crudgen`/`crudweb`；生成物当骨架最小适配，不推倒重写。
- **复用优先（铁律 9）**：本子系统**零新增表/列**；所有数据读复用既有 `aip_*` / `permissions` / `role_has_permission` / 既有审计设施。若 T-01 勘查推翻此结论，须按 R4 写"复用不成立"论证并补 `sql/incremental/` DDL，否则打回。
- **大工程拆分边界（铁律 15）**：每条任务标注「本子系统负责」与「不碰」；跨子系统一律落成"调用上游契约接口"。**S5 的 C-022 控制器暴露由 S5 负责，S4 只消费，禁止在 S4 重写（spec 边界 #4）**。S4 进 `code` 前须 S5 的 C-022 达 `test`（SPECS_INDEX §4）。
- **权限双闸（R6）**：新增宿主路由必做 `permissions` + `role_has_permission` 登记并执行 `loaddbinfo`，否则 403；新增页面必做 C-024 菜单登记，否则看不到入口（R2）。
- **编译约束**：AI 不运行 `cjpm build`；编译/类型检查/lint 由人工执行回传。
- **DDL 落点**：所有 `permissions`/`role_has_permission`/菜单节点登记脚本落 `sql/incremental/`，本子系统无表结构变更（仅数据登记）。

## 任务详细说明（按编号展开）

### T-01 勘查既有控制器/路由/表，确认新增只读端点路径与复用表清单
- **目标**：闭环 spec §6.5 待确认项（MCP 摘要/诊断端点、AIP 会话列表端点、工具审计端点、审计存储位置、菜单节点标识），落实 design §4 的 8 表复用论证。
- **本子系统负责**：勘查并产出结论。
- **不碰**：S5 的 C-022 控制器暴露（归 S5）；不修改既有协议端点。
- **步骤**：
  1. 读 `routes/mcp/McpRoute.cj`、`routes/mcpopen/McpOpenRoutes.cj`、`routes/webmcp/WebMCPRoutes.cj`、`routes/aip/AipRoute.cj`、`routes/ToolRoutes.cj` 确认现有端点与是否需补只读端点。
  2. 读 `aip_agent_identity`/`aip_agent_description`/`aip_discovery_cache`/`aip_interaction_session` 及消息落点模型，确认 8 表复用。
  3. 勘查既有审计/操作日志设施，确认 `tools/audit` 复用表（不新建）。
  4. 勘查 web-admin 现有菜单数据，确认 C-024 菜单节点 `component` 标识。
- **产出**：勘查结论回填 design §4.2 / §5.1 / §10.1 待确认项。
- **验收**：design 中所有"(待确认)"项均有结论；复用论证成立（无新表）或按 R4 论证。
- **风险**：若发现必须新增表/列，触发 R4 论证流程，否则打回。

### T-02 后端新增 MCP 运维摘要只读端点（cangjie）
- **目标**：spec §5.1.1#4（现有 MCP 仅流端点时补 UI 必需只读运维摘要）。
- **本子系统负责**：新增 `McpOpsController.summary` 只读聚合端点。
- **不碰**：C-014 协议语义/状态机（spec 边界 #1）；不新建表。
- **步骤**：在 `src/app/routes/uctoo/mcp/` 下按 AutoRoute 规范新增 `GET /api/v1/uctoo/mcp/ops/summary`，聚合 C-014 运行态 + WebMCP 4 端点返回；**AI 不运行 `cjpm build`，由人工编译回传**。
- **产出**：端点 + 路由注册；**无 DDL**（仅读既有运行态）。
- **验收**：返回 `McpOpsSummary`；单区域失败仅标 `partialFailures`，不阻塞其他区（spec §4.2#2）。
- **风险**：路径以 T-01 勘查确认为准；复用既有认证中间件（401/403）。

### T-03 后端新增 AIP 会话列表只读端点（cangjie）
- **目标**：spec §5.3.1#3（现有路由无法列出会话时补只读列表端点）。
- **本子系统负责**：新增 `AipOpsController.sessions` 只读端点。
- **不碰**：不扫描表 CRUD 接口替代（spec §5.3.1#3）；不新建表。
- **步骤**：新增 `GET /api/v1/uctoo/aip/sessions`，只读 `aip_interaction_session`；受 `limit/page` 服务端限制。
- **产出**：端点 + 路由；**无 DDL**。
- **验收**：返回会话列表；无 `sessionId` 时经此端点取数（spec §5.3.1#3）。
- **风险**：若 C-017 现有路由已支持列表，则本端点降级为"调用上游"动作，不重复实现（铁律 9）。

### T-04 后端新增 工具审计查询只读端点（cangjie，复用既有审计设施）
- **目标**：spec §5.4.1#4（工具路由无审计查询时补只读端点）。
- **本子系统负责**：新增 `ToolAuditController.audit` 只读端点。
- **不碰**：审计**存储**复用既有设施，**不新建表**（spec §6.5#5 + R4）；不碰 S5 C-022。
- **步骤**：新增 `GET /api/v1/uctoo/tools/audit`，查询既有审计表，过滤 `operator/action/toolName`，不返回凭据/完整正文。
- **产出**：端点 + 路由；**无新表，仅复用**。
- **验收**：审计员查得授权范围内记录；敏感字段不泄露（spec §4.3#4）。
- **风险**：审计具体表名待 T-01 勘查确认；无论结论如何不新建表。

### T-05 新增端点 permissions + role_has_permission 登记（sql/incremental/）
- **目标**：spec §1.3 / §4.3#5（R6 双闸，缺登记即 403）。
- **本子系统负责**：为 T-02/T-03/T-04 三个新增端点 + 前端操作路由写登记脚本。
- **不碰**：不建设通用权限平台（spec 边界 #5）。
- **步骤**：
  1. 在 `permissions` 登记 3 个端点 `permission_name`/`path`/`method`。
  2. 在 `role_has_permission` 按协议管理员/安全审计员/低权限用户角色写入。
  3. 落 `sql/incremental/ConsoleClosure--protocol-gateway_permissions.sql`。
  4. 执行 `loaddbinfo` 刷新（或退 Web 端「数据库管理→加载数据库信息」，见 tasks 规范工具链坑位）。
- **产出**：`sql/incremental/*.sql` + 刷新完成证据。
- **验收**：低权限用户直达新接口返回 403（spec §5.4.1#3）。
- **风险**：R6 —— 漏登记表现为 403，易误判前端 bug，务必 100% 覆盖。

### T-06 Web 前端：MCP/WebMCP 运维页（web-coder）
- **目标**：spec §5.1（D1-D2）。
- **本子系统负责**：构建运维视图。
- **不碰**：不重实现 C-014/C-015 协议语义；不修改既有协议端点。
- **步骤**：页面进入并行请求 T-02 `summary` + `open/tools` + WebMCP 4 端点；诊断经用户确认后发 C-014 JSON-RPC；单区失败独立标记；展示结果与审计关联标识。
- **产出**：MCP/WebMCP 运维视图组件。
- **验收**：D1（状态隔离展示）、D2（目录/调用分离，仅看目录不发调用）验收条件通过。
- **风险**：首屏 ≤3s 骨架；单接口超时独立失败（spec §4.1#2）。

### T-07 Web 前端：AIP 身份与能力页（web-coder）
- **目标**：spec §5.2（D3-D4）。
- **本子系统负责**：构建身份/能力视图。
- **不碰**：调用 `AipRoute.cj:29-39` 既有端点，不改写语义。
- **步骤**：身份全生命周期操作 + 能力描述发布/更新；禁用/锁定/吊销/互联注册/能力发布前弹确认框展示 `agentId`+动作，确认前请求数=0；缺互联权限隐藏入口。
- **产出**：AIP 身份/能力视图组件。
- **验收**：D3（状态刷新）、D4（不前端改写描述语义）验收条件通过。
- **风险**：互联失败保留服务端原状不造前端临时身份（spec §5.2.3#1）。

### T-08 Web 前端：AIP 发现/会话/模式页（web-coder）
- **目标**：spec §5.3（D5-D7）。
- **本子系统负责**：构建发现/会话/模式视图。
- **不碰**：不扫描表 CRUD 替代；消息分页受服务端 `limit/page` 限制。
- **步骤**：发现/缓存刷新/清理；会话创建+消息分页（按 `limit/page`）；模式切换受控+回读双健康；缓存/会话不可用提示刷新不标旧数据为最新。
- **产出**：发现/会话/模式视图组件。
- **验收**：D5（刷新缓存）、D6（消息分页顺序）、D7（模式切换回读）验收条件通过。
- **风险**：无 `sessionId` 时经 T-03 列表端点取数。

### T-09 Web 前端：工具网关页（web-coder）
- **目标**：spec §5.4（D8）。
- **本子系统负责**：构建工具网关视图。
- **不碰**：C-022 实现归 S5；S4 仅消费。
- **步骤**：消费 C-018 `list`/`info`/`call`；按 `sensitiveLevel`/`requiresConfirmation`/`auditEnabled` 展示；敏感工具确认前不发调用；审计员经 T-04 `audit` 查记录；预留 C-022 能力展示位（接 T-11）。
- **产出**：工具网关视图组件。
- **验收**：D8（目录/详情/受控调用/审计）验收条件通过。
- **风险**：未认证 401、工具不存在 404、权限/确认不足 403（spec §5.4.3）。

### T-10 C-024 动态菜单登记（页面节点 + component 挂载）
- **目标**：spec §1.3 / §4.3#5（R2，漏登记即"看不到入口"）。
- **本子系统负责**：登记菜单节点 + 前端 component 挂载。
- **不碰**：不建通用权限平台。
- **步骤**：在 C-024 菜单树增协议网关分组节点（含 `component` 指向 T-06~T-09 视图）；落 `sql/incremental/ConsoleClosure--protocol-gateway_menu.sql`；前端 `views/...vue` 就位。
- **产出**：菜单节点 + 组件；低权限用户无入口。
- **验收**：超管可见入口；低权限用户无菜单项且直达接口 403（SPECS_INDEX §5.2 异常用例）。
- **风险**：R2 —— 漏登记表现为"做了但找不到"，L3 用例显式校验入口可见。

### T-11 工具网关接入 S5 C-022 能力并完成 L2 主干调用（调用上游契约）
- **目标**：spec §5.4.1#5（S5 经 C-022 暴露能力进入工具体系，列出并完成一次授权调用）。
- **本子系统负责**：在工具网关页消费 C-022 暴露的能力。
- **不碰（铁律 15）**：**S5 的 C-022 控制器暴露由 S5 负责**，S4 不重写；仅消费其暴露后的接口。
- **步骤**：等待 S5 的 C-022 达 `test`；工具网关页拉取已暴露能力并展示；对其中一项完成一次授权调用；标记"已暴露但未真正接入"的能力不得谎称可用（SPECS_INDEX §7 R3）。
- **产出**：C-022 能力在目录展示 + 一次授权调用成功证据。
- **验收**：L2 主干用例"为新暴露的能力接口加路由→协议网关页能列出并完成一次调用"通过（SPECS_INDEX §5.2#3）。
- **风险**：**阻塞于 S5 达 test**；若 S5 标注"已暴露但未真正接入"，S4 不得向前端谎称可用（R3）。

### T-12 L1 自测 + 跨边界 L2 冒烟（≥3 主干 + 1 异常）与权限异常用例
- **目标**：spec §4.4#3（C-014~C-018 每项≥1 主干冒烟；S5→S4 ≥3 主干+1 异常）。
- **本子系统负责**：组织验证。
- **不碰**：S5 上游实现（在 S5 done 态上集成）。
- **步骤**：
  1. L1：本子系统 spec 每条 EARS 验收条件通过；P0 缺陷清零。
  2. L2 主干（≥3）：① MCP 诊断走 C-014 回显；② AIP 身份操作调 C-016 刷新；③ 工具网关列 C-022 能力并调用。
  3. L2 异常（1）：低权限用户打开工具安装/调用页 → 无菜单入口 + 直达 403。
  4. 故障隔离验收覆盖 MCP/AIP/WebMCP/工具网关 4 区（spec §4.2#2）。
- **产出**：冒烟用例集 + 验收证据（test 步 `test-report.md` 另出，本文件不创建）。
- **验收**：SPECS_INDEX §5 L2 判据全绿；否则主工程闸口不予确认。
- **风险**：未跑 L2 报 done 将被主工程硬闸驳回（SPECS_INDEX §5.3）。
